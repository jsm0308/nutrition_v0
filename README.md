# 다음 급식 (School Meal Balance)

학교 급식으로 채운 영양을 먼저 계산한 뒤, 남은 하루의 아침·저녁·간식 조합을 비교하는 청소년 식단 최적화 데모입니다.

## 무엇을 계산하나

청소년에게 점심은 이미 학교 급식으로 정해져 있다는 현실을 먼저 반영했습니다. 선택한 급식의 영양을 하루 목표에서 뺀 뒤, 남은 격차를 아침·저녁·간식으로 보완할 수 있는 조합을 찾습니다.

- 13~18세의 나이·성별·활동량, 하루 예산, 제외 식품을 입력합니다.
- 세 가지 급식 예시 중 하나를 선택합니다.
- 아침·저녁·간식 후보 36개를 전수 비교합니다.
- 총비용, 영양 목표 대비 비율, 제약 충족 여부를 함께 보여 줍니다.

같은 입력에는 항상 같은 결과를 반환합니다. 공개 데모는 15개 식품의 시연용 영양·가격 데이터만 사용하며, 실제 학교 급식 조회나 공인 영양 기준 연동은 제공하지 않습니다.

## 계산 방식

각 후보 식단은 영양 목표와의 차이, 부족 영양소 패널티, 예산 초과 패널티, 제외 식품 포함 여부를 합산해 평가합니다. 점수가 가장 낮은 조합을 결과로 보여 줍니다. Python 구현은 [optimizer.py](optimizer.py), 브라우저 구현은 [index.html](index.html)에서 확인할 수 있습니다.

## 로컬 실행과 검증

Python 3.10 이상이면 별도 패키지 설치 없이 실행할 수 있습니다.

~~~bash
python app.py
~~~

브라우저에서 `http://127.0.0.1:8103`을 열면 됩니다. `GET /api/health`, `POST /api/optimize` API도 제공합니다.

~~~bash
python -m unittest discover -s tests -v
~~~
