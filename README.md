# 청소년 식단 최적화 데모

원본 프로젝트의 방향은 청소년의 권장 영양 기준, 실제 섭취·급식 데이터, 식품 영양 정보를 함께 보고 식단 후보를 고르는 것이었다. 이 저장소에는 실행 가능한 포트폴리오 데모를 추가했다. 사용자가 나이·성별·활동량·예산·알레르기 또는 제외 식품을 입력하면, 포함된 소규모 식품 목록에서 하루 식단을 계산한다.

> 팀장으로 참여한 프로젝트의 데모 보강본이다. 원본 README에 있던 KDRIs·NEIS·식품 영양 DB 연계 방향은 유지하되, 이 버전은 외부 데이터나 API 없이 재현되도록 축소했다.

대회 당시의 데이터 분석, 타깃 피벗, ILP 설계 기록은 [`README_PROJECT_ORIGINAL.md`](README_PROJECT_ORIGINAL.md)에 내용 그대로 보존했다. 아래 문서는 현재 저장소에서 바로 실행되는 데모의 범위와 한계를 설명한다.

## 실행

Python 3.10 이상이면 별도 패키지 설치 없이 실행한다.

```bash
python app.py
```

브라우저에서 `http://127.0.0.1:8103`을 연다. 다른 포트가 필요하면 `python app.py --port 9000`처럼 지정한다.

## 확인

```bash
python -m unittest discover -s tests -v
```

- `GET /api/health`: 서버 상태를 반환한다.
- `POST /api/optimize`: 입력 조건에 맞는 식단 계산 결과를 반환한다.

## 계산 방식

아침·점심·저녁·간식의 소규모 후보를 전수 비교한다. 각 후보는 열량, 단백질, 식이섬유, 칼슘, 철의 목표 차이와 예산 초과 패널티로 점수를 매긴다. 단백질·식이섬유·칼슘·철이 모자란 경우에는 추가 패널티를 준다. 알레르기 태그와 제외 식품이 들어간 후보는 비교 대상에서 제외한다.

원본 설계에는 정수 선형계획법(ILP)이 제안되어 있다. 이 데모는 식품 후보가 작아 계산 과정을 바로 확인할 수 있는 전수 비교 방식을 택했다. 같은 입력에는 같은 결과가 나온다.

## 범위와 한계

- 포함 식품의 영양·가격 값은 시연용 소규모 추정치다. KDRIs, NEIS, 식품영양성분 DB를 실시간으로 조회하지 않는다.
- 목표치 계산은 입력 흐름을 보여주기 위한 단순 모델이며, 공식 권장량이나 개인 건강 상태를 반영하지 않는다.
- 알레르기, 질환, 약물, 성장 상태를 포함한 실제 식단 결정에는 영양사·의료진 검토가 필요하다.
- 따라서 이 앱은 의료 또는 영양 상담 도구가 아니라 제약 조건을 반영하는 추천 흐름의 데모다.

## 실서비스 전환 조건

1. 공인 영양 기준과 식품 영양 DB의 버전·출처를 고정하고 검증한다.
2. 학교 급식·가격·재고 데이터의 갱신 주기와 누락 처리 기준을 설계한다.
3. 알레르기와 건강 정보의 동의·보관·접근권한 정책을 마련한다.
4. 영양 전문가가 제약식과 추천 결과를 검토하는 절차를 넣는다.
5. 실제 운영 규모에서는 ILP 해법, 대체 식품 규칙, 실패 시 설명을 함께 평가한다.
