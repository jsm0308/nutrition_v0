# 급식 다음 (School Meal Balance)

학교 급식으로 채운 영양을 먼저 계산하고, 남은 하루의 아침·저녁·간식 조합을 비교하는 청소년 식단 최적화 데모입니다.

### [브라우저에서 바로 실행하기](https://jsm0308.github.io/school-meal-balance/)

## 왜 급식을 먼저 고정했나

이 프로젝트는 처음에는 여러 연령대의 영양 격차를 비교하는 분석으로 시작했습니다. 데이터를 살펴보며 청소년의 불균형에 주목했고, 청소년은 평일 점심을 자유롭게 고르기 어렵다는 현실을 반영해 문제를 다시 정의했습니다.

> 학교 급식은 이미 먹었다고 보고, 하루 목표에서 급식 영양을 뺀 다음 무엇으로 보완할지 계산한다.

## 현재 데모에서 되는 것

- 13~18세의 나이·성별·활동량 입력
- 세 가지 학교 급식 예시 중 하나 선택
- 하루 예산과 유제품·계란·생선·대두·글루텐 제외 조건 반영
- 급식을 고정한 뒤 아침·저녁·간식 후보 36개 전수 비교
- 총비용, 영양 목표 대비 비율, 제약 충족 여부 설명
- GitHub Pages에서 별도 서버 없이 즉시 실행

같은 입력은 항상 같은 결과를 냅니다. 공개 데모는 15개 식품의 시연용 영양·가격 데이터만 사용하며, 실제 학교 급식 조회나 공인 영양 기준 연동을 가장하지 않습니다.

## 계산 방식

각 후보 식단에 대해 다음 항목을 함께 평가합니다.

1. 열량·단백질·식이섬유·칼슘·철분 목표와의 차이
2. 단백질·식이섬유·칼슘·철분 부족분에 대한 추가 패널티
3. 입력 예산을 넘긴 금액에 대한 패널티
4. 제외 식품 포함 여부

점수가 가장 낮은 조합을 결과로 보여 줍니다. Python 구현은 [optimizer.py](optimizer.py), 브라우저용 동일 로직은 [index.html](index.html)에서 확인할 수 있습니다.

## 로컬에서 실행

Python 3.10 이상이면 별도 패키지 설치 없이 실행할 수 있습니다.

~~~bash
python app.py
~~~

브라우저에서 http://127.0.0.1:8103 을 엽니다. API는 GET /api/health, POST /api/optimize 를 제공합니다.

~~~bash
python -m unittest discover -s tests -v
~~~
